# ABO Academy — Planejamento Estratégico Evolucionário

[Visualizar apresentação](https://abo-planejamento-evolucionario.rafagatuzzo.chatgpt.site/)

Landing page do PEE, construída em React/Vinext, com identidade visual ABO, fontes Hando e infográficos.

## Desenvolvimento

Requer Node.js 22.13 ou superior.

```sh
npm ci
npm run dev
```

## Produção

```sh
npm run build
```

Imagens e fontes em `public/`. Esta implementação não é um template nativo do Elementor.
